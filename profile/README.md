# Omarchy QOL

Quality of life with opinions.

Plugins that make Omarchy easier to use without blowing up your system.

Around here, QoL means:

- start with what Omarchy already ships instead of reinventing it
- improve what’s obviously wrong or ill-designed, but keep the fix
  minimal
- stay quiet when idle and consume minimal memory
- ship with an uninstall button, so you can uninstall my **BLOAT** :)
  from your beloved system (I’d rather get an issue on the plugin page, though)

Independent community work by [@ilyaZar](https://github.com/ilyaZar). Not
affiliated with or endorsed by Omarchy or Omacom (don’t-sue-me for the icon).
