# Omarchy QOL

Quality of life, with opinions.

Focused plugins that make Omarchy easier to live in. Every plugin aims to feel
native, stay quiet when idle, explain its tradeoffs, respect existing
configuration, and leave cleanly.

Independent community work by [@ilyaZar](https://github.com/ilyaZar). Not
affiliated with or endorsed by Omarchy or Omacom.
